Calculation notes

Level scaling follows the source sheet: ATK/MATK = base × (1 + level/10), HP = base × (1 + level/5), with the sheet's MAX values used at cap. Gear main stats use two copies of the tier main value plus refinement increments; substats use the tier substat values. Crit damage is treated as bonus damage (50% = ×1.5). With advantage enabled, property damage uses the sheet's base 50% plus gear/buff property damage. Chain damage adds 10% per chain plus the optional chain-buff input.

Data source: “Copy of Brown Dust II — Gear Calculator” by Kane. Static GitHub Pages build; no account or server required.
